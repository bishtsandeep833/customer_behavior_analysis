# 📊 Data Analytics Project

## 🚀 Overview

This project demonstrates a complete Data Analytics workflow, from raw data processing to business insights. The project involves loading and analyzing a dataset in Python, performing Exploratory Data Analysis (EDA), cleaning and transforming data, running SQL queries, building an interactive Power BI dashboard, creating a detailed analytical report, and presenting findings through a professional Gamma presentation.

The objective is to convert raw data into actionable insights that support data-driven decision-making.

## 🔄 Project Workflow

### 1️⃣ Data Loading

* Imported dataset into Python.
* Examined data structure and column information.
* Verified data types and dataset dimensions.

### 2️⃣ Exploratory Data Analysis (EDA)

* Analyzed distributions and trends.
* Identified patterns and anomalies.
* Created visualizations for better understanding.

### 3️⃣ Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected inconsistent data.
* Standardized data formats.

### 4️⃣ SQL Analysis

* Imported cleaned data into PostgreSQL/MySQL/SQL Server.
* Executed SQL queries to:

  * Filter records
  * Aggregate data
  * Perform joins
  * Calculate KPIs
  * Generate business insights

### 5️⃣ Power BI Dashboard Development

* Connected transformed data.
* Built interactive visualizations.
* Added filters, slicers, and KPIs.
* Created business-focused dashboard pages.

### 6️⃣ Report Creation

* Documented methodology.
* Summarized findings and insights.
* Highlighted key performance indicators.

### 7️⃣ Gamma Presentation

* Developed a professional presentation.
* Included project objectives, methodology, dashboard screenshots, and recommendations.

## ▶️ How to Run the Project

### 🐍 Python Analysis

Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

Run the Jupyter Notebook:

```bash
jupyter notebook
```

Execute all notebook cells sequentially.

---

### 🗄️ SQL Analysis

1. Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
2. Open the SQL script file.
3. Run the queries to generate insights.

---

### 📈 Power BI Dashboard

1. Open the `.pbix` file.
2. Refresh data connections.
3. Explore dashboard pages and visualizations.
